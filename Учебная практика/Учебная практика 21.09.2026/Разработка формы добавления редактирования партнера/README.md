# Разработка формы добавления/редактирования партнера

## Реализовано

- Отдельная страница карточки открывается в режиме добавления или редактирования.
- Для редактирования `partner_id` передается через URL, а значения полей берутся из демонстрационного набора.
- Форма содержит наименование, тип партнера, рейтинг, адрес, ФИО директора, телефон и email компании.
- Тип выбирается из выпадающего списка: ООО, АО, ЗАО, ИП, ПАО.
- Рейтинг ограничен целым неотрицательным числом (`min=0`, `step=1`).
- Для телефона и email есть примеры ожидаемого формата; email проверяется браузером.
- Кнопки «Назад» и «Отмена» возвращают к реестру.

## Запуск

Из этой папки:

```bash
python3 -m http.server 8004
```

Откройте `http://127.0.0.1:8004/index.html`.

## Границы этапа

Реестр и карточка используют демонстрационные данные из `partners-data.js`. Кнопка «Сохранить» проверяет браузерную валидность формы, но не записывает данные. Загрузка актуальной записи из БД, `INSERT`/`UPDATE` и обновление реестра после сохранения относятся к следующему заданию — интеграции формы с БД.
