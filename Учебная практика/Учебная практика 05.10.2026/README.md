# Учебная практика 05.10.2026

Итоговая сборка предыдущих практик: ETL и 3NF-хранилище, бизнес-логика, единый UI с навигацией/CRUD/историей/калькулятором и комплексный аудит.

## Задания

1. `Инфраструктура данных и ETL (База данных в 3NF)` — исходные CSV из DEV, DDL, очистка/импорт, отчет по отклоненным строкам и контрольные counts.
2. `Реализация ядра бизнес-логики (Расчеты и алгоритмы)` — скидка и расчет материала с общими справочниками.
3. `Разработка UI, навигации и CRUD-форм` — итоговое приложение: реестр, карточка, история продаж и калькулятор.
4. `Автоматизированное тестирование, аудит безопасности и UX` — единый запуск тестов и отчет аудита параметризации, валидации и UX.

## Порядок сборки

1. Настройте PostgreSQL и выполните ETL из задания 1. Данные загружаются в отдельную схему `practice_2026_10_05`, прежние схемы практик не заменяются.
2. Запустите приложение из задания 3, подключив его к той же схеме.
3. Из задания 4 запустите интегрированный тестовый набор и ознакомьтесь с отчетом аудита.

В каждой папке задания находится собственный README с командами запуска и деталями проверки.
