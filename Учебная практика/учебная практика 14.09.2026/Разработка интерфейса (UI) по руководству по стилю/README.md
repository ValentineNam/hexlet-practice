# CRM: Список партнеров и скидок

## Описание

Это mock-версия интерфейса CRM-системы: страница показывает список партнеров и их скидки, но данные берутся из локального массива заглушек, а не из PostgreSQL.

В интерфейсе используются:
- заголовок страницы,
- иконка приложения,
- логотип компании,
- карточки партнеров,
- геометрические логотипы,
- единый визуальный стиль по руководству по стилю.

## Структура проекта

- `index.html` — основная страница
- `styles.css` — стили интерфейса
- `partners-data.js` — локальный массив заглушек
- `app.js` — инициализация UI из mock-данных
- `render.js` — рендер карточек партнеров
- `logo.js` — генерация логотипа по форме и букве
- `assets/` — статические файлы интерфейса
- `page_sample.png` — пример страницы для визуальной сверки

## Как запустить mock-режим

```bash
cd "Учебная практика/учебная практика 14.09.2026/Разработка интерфейса (UI) по руководству по стилю"
python3 -m http.server 8001
```

Затем открыть в браузере:

```text
http://127.0.0.1:8001/index.html
```

## Что важно понимать

Это отдельный демонстрационный режим. Здесь данные не связаны с БД и служат для проверки визуального интерфейса и верстки.

## Источник данных

Карточки формируются из локального массива в `partners-data.js`.

Предназначение этой папки:
- показать корректный UI;
- проверить, что верстка и карточки работают без подключения к PostgreSQL;
- сохранить отдельную mock-демонстрацию как эталон или промежуточный этап.
