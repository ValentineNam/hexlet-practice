# Наполнение интерфейса, отладка и стресс-тестирование

## Описание

Эта папка содержит живой режим интерфейса: страница работает не со статическими заглушками, а с данными из PostgreSQL. Здесь мы формируем реальную выборку партнеров, проверяем корректность скидок и затем подключаем их к UI.

## Что находится в папке

- `generate_partners_seed.sql` — генератор 100 партнеров и истории продаж;
- `index.html` — интерфейс страницы;
- `app.js` — загружаются данные из `/api/partners`;
- `render.js` — отрисовка карточек;
- `logo.js` — генерация логотипов;
- `server.py` — локальный HTTP-сервер, который отдает JSON из БД;
- `styles.css` — стили в том же визуальном шаблоне, что и в mock-версии.

## Зачем это нужно

Основная цель — проверить работу интерфейса в сценарии реального приложения:
- данные берутся из PostgreSQL;
- рассчитывается скидка по бизнес-логике;
- UI отображает актуальный список партнеров;
- часть партнеров остаётся с 0%, часть получает 5/10/15%.

## Как запустить live-режим

1. Убедиться, что PostgreSQL запущен и БД доступна.
2. Выполнить SQL-генератор:

```bash
cd "Учебная практика/учебная практика 14.09.2026/Наполнение интерфейса, отладка и стресс-тестирование"
python3 - <<'PY'
from pathlib import Path
import psycopg2
sql = Path('generate_partners_seed.sql').read_text(encoding='utf-8')
conn = psycopg2.connect(host='localhost', port='5432', dbname='practice_2026_autumn', user='v.nam', password='')
cur = conn.cursor()
cur.execute(sql)
conn.commit()
cur.close()
conn.close()
print('Seed applied')
PY
```

3. Запустить сервер:

```bash
cd "Учебная практика/учебная практика 14.09.2026/Наполнение интерфейса, отладка и стресс-тестирование"
python3 server.py
```

4. Открыть страницу:

```text
http://127.0.0.1:8002/index.html
```

5. Проверить API:

```text
http://127.0.0.1:8002/api/partners
```

## Что важно помнить

- Эта папка — не mock-демо, а реальный рабочий режим с данными из базы.
- Сценарии проверки здесь включают:
  - пустую историю продаж;
  - 0% по скидке;
  - 5/10/15% по бизнес-логике;
  - корректную работу API и UI в связке с PostgreSQL.

## Поля таблицы `partners`

- `partner_id`
- `company_name`
- `inn`
- `contact_email`
- `phone`
- `rating`

## Формат телефонов

Телефоны сохраняются в формате:

- `+79991112233`
- `+79041112233`
- `+78125554433`

То есть без пробелов, скобок и тире.

## Что проверяется после запуска

- общее количество партнеров;
- наличие партнеров без продаж;
- корректная работа логики скидки при 0%, 5%, 10%, 15%;
- отсутствие ошибок при `SUM(quantity) = 0` и `NULL`.
