# Наполнение интерфейса, отладка и стресс-тестирование

## Что делает скрипт

Скрипт `generate_partners_seed.sql` предназначен для наполнения таблицы `partners` до 100 записей и формирования истории продаж для каждого нового партнера.

Основная идея:
- если в `partners` уже 100 или больше записей — ничего не меняем;
- если меньше 100 — добираем недостающие партнеры;
- каждому новому партнеру создается история продаж от 0 до 5 отгрузок.

Это нужно для проверки сценариев:
- партнер без продаж;
- партнер с небольшим количеством продаж;
- партнер с заметной историей, для которой рассчитывается скидка;
- корректного поведения UI при `SUM(quantity) = 0` или `NULL`.

## Почему так важно

В таблице `partners` нет полей с количеством отгрузок или скидкой. Это вычисляемые значения, которые берутся из таблиц `shipments` и `shipment_items`.

Поэтому генератор формирует не только карточки партнеров, но и их реальную историю продаж, чтобы UI мог корректно отображать процент скидки и не падать на пустых данных.

## Важная особенность

Скрипт подготовлен для анализа и ручного запуска. Он не должен быть выполнен автоматически без предварительной проверки.

## Поля таблицы `partners`

- `partner_id`
- `company_name`
- `inn`
- `contact_email`
- `phone`
- `rating`

## Формат телефонов

Телефоны хранятся в формате:

- `+79991112233`
- `+79041112233`
- `+78125554433`

То есть без пробелов, скобок и тире.

## Что будет проверяться после запуска

- общее количество партнеров;
- наличие партнеров без продаж;
- корректная работа логики скидки при 0% и при ненулевой истории;
- отсутствие падений на `NULL`/`0` значениях.
