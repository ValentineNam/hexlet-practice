# Расчет скидки для партнера

## Описание задачи

В этом модуле реализована изолированная функция расчета скидки в зависимости от общего количества товаров.

Правило:
- меньше 10000 — 0%
- от 10000 до 49999 — 5%
- от 50000 до 299999 — 10%
- 300000 и больше — 15%

## Файл с логикой

- `discount.py` — содержит функцию `calculate_partner_discount(total_quantity: int) -> int`

## Файл с тестами

- `test_discount.py` — проверяет граничные значения, включая переходы между диапазонами

## Как запустить тесты

Из этой директории выполните команду:

```bash
python3 -m unittest -v test_discount.py
```

Также можно запустить напрямую:

```bash
python3 test_discount.py
```

## Проверяемые граничные значения

- 9999 → 0
- 10000 → 5
- 49999 → 5
- 50000 → 10
- 300000 → 15

## Результат

Тесты должны завершиться успешно:

```text
Ran 1 test
OK
```
